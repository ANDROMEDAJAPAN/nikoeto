## 1. ご提案の背景

このたびは、ロゴ制作のご相談をお受けいただきありがとうございます。
制作費のお見積りについて、弊社の予算との間に開きがあることから、**差額に相当する対価として「金銭以外の価値あるもの」をご提供できないか**と考え、本提案をまとめました。

弊社はWebサイト制作・デジタルマーケティングを事業として行っております。その専門領域で、仁胡さまの作品活動に長期的に貢献できるものとして、**公式ギャラリーサイトの制作および継続運営**をご提案いたします。

## 2. ご提供内容

### (1) 公式ギャラリーサイトの制作(本リポジトリのサイト)

現在のBASEショップの構成(作品一覧・ABOUT・CONTACT)を土台に、**作品一点一点が主役になる**ギャラリーサイトを制作しました。

| 現在のBASEショップ | 新サイト |
|---|---|
| テンプレートによる均一なグリッド表示 | 一点ごとの「舞台」— 余白・大きな文字・作品への言葉を添えた展示 |
| 静止画のみ | **墨が動き出す映像表現**(作品写真から生成した動画3点)+ スクロール演出 |
| 世界観の演出が難しい | 和紙・墨・朱(落款)を基調とした独自の世界観、縦書き・円相などの書のモチーフ |
| 日本語のみ | 作品名・要所に英語併記(海外のお客さまへの入口) |
| 「動」の演出はなし | **「動/静」切替ボタン** — 動きのある表現と、静かに作品と向き合う表示を鑑賞者が選べます |

- 販売・決済は引き続きBASEをご利用いただけます(サイトからBASEへ誘導する構成)。従来の運用を変える必要はありません。
- スマートフォン表示にも対応済みです。

### (2) 継続運営(弊社が無償で担当)

- 新作の掲載・完売表示の更新
- 作品撮影画像の調整・掲載文の作成
- 独自ドメインの取得・接続、公開・保守
- SEO(検索対策)・OGP(SNSシェア時の見え方)の整備

### (3) 作品プロモーション用の映像素材

作品写真から生成した「墨が動き出す」映像(舞・円相・感謝の3点)は、サイト掲載のほか **Instagramリール等でそのままご利用いただけます**。

## 3. 仁胡さまにとってのメリット

1. **作品の価値がそのまま伝わる場**
   テンプレートECの制約を離れ、ギャラリーで作品と向き合うような鑑賞体験をオンラインで提供できます。¥42,000〜という作品価格に見合う「格」のある見せ方は、価格への納得感・ブランド価値の向上に直結します。

2. **完売後も作品が営業を続ける**
   BASEでは完売作品は在庫切れ表示になりますが、本サイトでは「これまでの作品」として展示され続け、**オーダーメイド・命名書・屋号やロゴのご依頼の入口**として機能します。

3. **依頼導線の強化**
   「誂えの書」(オーダーメイド・命名書・屋号/ロゴ)を独立したセクションとして常設。Instagram DMへの導線も明確にし、法人・店舗からのご依頼獲得を後押しします。

4. **新しい表現としての「動く書」**
   書作品が墨のまま動き出す映像は、SNSでの拡散力が高く、他の書家との差別化になります。今後も新作ごとに制作可能です。

5. **費用負担ゼロの継続運営**
   サイトの更新・保守・ドメイン管理まで弊社が担当します。仁胡さまは制作活動に専念していただけます。
